# Work 与 Codex 协作流程

Work 用于讨论智能客服 Agent 的目标、架构和实施方案，Codex 用于阅读源码、实施及验证。双方以同一版本的项目文档交接，用户负责确认重要决策和授权实施。

## 文档职责

| 文件 | 记录内容 | 更新时机 |
| --- | --- | --- |
| architecture.md | 当前实际架构、实现状态、待定问题 | 初始化及已授权架构变化后 |
| decisions.md | 已确认决策、确认依据、替代关系 | 用户明确确认或修订决策后 |
| task.md | 一个当前任务的具体范围、基线、验收与授权 | 方案定稿、任务修订及状态变化时 |
| result.md | 对应任务的实际结果、验证和问题 | 每次实施结束或受阻时 |

Work 负责协助形成方案和任务草案；Codex 负责核对源码事实、实施及回写结果。可以由任何有文件访问能力的一方代写文档，但必须区分用户确认、提议和实现事实。

## 信息如何传递

同一个项目不保证不同会话能访问相同本地文件，也不保证聊天记录自动同步。本目录提供交接规范，不提供自动同步服务。

1. 若 Work 和 Codex 都能读取同一个工作目录或同一版本的仓库，交接时要求接收方重新读取文件，并核对任务编号、修订号和文档基线。
2. 若 Work 无法访问本地目录，将 `AGENTS.md` 和本目录五份文档作为同一批文件提供给 Work；后续有更新时重新提供对应版本，避免使用旧附件。
3. Work 不能直接回写时，让其输出完整的待更新文档内容或明确的修改清单，由用户交给 Codex 落盘。单纯落盘方案不意味着开始实施。
4. Codex 完成后，将最新 `task.md`、`result.md` 以及本轮改动过的架构和决策文档交回 Work。接收方应确认对应任务及修订号。

不依赖某一会话的隐藏记忆；新会话只读交接文档和相关源码，也应能判断下一步做什么。

## 从讨论到验收

1. **讨论**：梳理业务目标、使用渠道、知识来源、转人工边界、权限与隐私要求；将未确认选择保留为待定，不默认选择框架、模型或数据库。
2. **定稿**：记录已确认决策；填写任务目标、允许修改范围、不做事项、依赖和可检查的验收标准。重要决策没有确认时，任务保持草案。
3. **授权**：用户明确要求执行指定任务和修订版。把实际指令及出处写入授权记录；不得由 Agent 自行编造确认记录。
4. **实施**：Codex 核对当前文档及源码，更新任务状态，实施已授权范围。阻塞问题写入结果后交回讨论。
5. **交接**：Codex 写入结果，任务进入待验收。Work 可协助评估结果，但后续改进建议需要形成任务并获得相应实施授权。
6. **验收**：用户明确接受后标记已验收；若需修订，记录反馈及适用授权范围。

任务状态使用：草案、待实施、实施中、受阻、待验收、已验收、已取消。状态用于追踪，不替代实际授权。

## 版本与冲突处理

- 任务编号用 `TASK-001` 等稳定编号，修订号从 1 开始。改变目标、范围、验收标准或关键方案时递增修订号；只更新进度无需递增。
- 授权绑定任务及修订版。修订版中的新增或变化范围需要明确授权，不能沿用旧版授权推定同意；用户最新指令已经明确涵盖变更时，直接记录该依据。
- 任务注明引用的架构版本、决策编号和源码基线。有 Git 时记录提交号和相关未提交修改；无 Git 时如实说明，并按文件内容核对。
- 原任务或结果即将被替换时，先复制到 `docs/history/<任务编号>/r<修订号>-<两位轮次>-task.md` 与相应的 `-result.md`。选择未占用轮次，保留历史文件。首次没有实施结果时无需归档。
- 决策采用追加记录和明确的替代关系，不静默改写已确认历史。文档版本冲突或源码偏离方案时，记录具体差异和影响再讨论。

## 可复制的交接提示词

### 发给 Work

> 请先读取本项目 AGENTS.md 与 docs 下的协作文档，并核对当前任务编号和修订号。依据当前源码事实和最近实施结果，与我讨论下一步方案。区分已确认决策与待定建议，输出需要更新的 architecture.md、decisions.md 和 task.md 内容。没有我的明确实施指令，不要求 Codex 修改业务代码。无法访问文件时请说明，不假定已读取。

### 仅让 Codex 更新方案文档

> 请将以下讨论结果更新到项目文档，核对现有文档和源码是否冲突。仅更新协作文档，本次不授权业务实现。未确认的技术选择保持待定，发现冲突请记录并提交讨论。

### 授权 Codex 实施

> 请读取 AGENTS.md、docs 下的协作文档及相关源码，实施 docs/task.md 中 TASK-XXX 第 N 修订版。我授权执行其中明确列出的范围。若有重大冲突请记录后提交讨论；完成后写回 docs/result.md 并更新任务状态。

### 将实施结果交回 Work

> 这是 TASK-XXX 第 N 修订版的最新任务和实施结果，以及更新后的架构与决策文档。请依据实际修改和验证证据检查方案是否落实，讨论遗留问题。新的建议先形成任务草案，不视为已获实施授权。
