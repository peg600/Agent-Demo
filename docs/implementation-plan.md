# 嘉德客服分阶段实施与验收

本计划承接TASK-002 r1的设计交付。TASK-006已完成拍卖目录代码和演示数据，尚待数据库/浏览器联调；完整客服仍按下面阶段实施。技术基线见architecture.md，不能把计划状态当作实现证据。

TASK-003已准备M1的基础工程；TASK-006实现M2中的拍场查询/规则推荐及对应父级拍卖会模型；TASK-007实现M1的匿名身份归属、会话与历史消息代码，尚待真实数据库和浏览器联调。其余业务表、检查点初始化、SSE与模型集成仍未实现，M1/M2整体尚未验收。

## M0 本地基础设施

范围：Docker Desktop 可用、业务 PostgreSQL、RAGFlow CPU 栈、OpenAI 配置。先不启 Langfuse，先不导入大 PDF。

验收：Docker Server 可达；PG select 1 成功；RAGFlow healthz 与管理页可用；5–10 份演示文档索引完成；直接检索能返回正确片段与文档 ID；一次真实模型结构化输出成功。保存服务版本和镜像 digest。不能以 compose config 通过代替这些检查。

## M1 工程骨架和历史会话

范围：pnpm workspace、Vue/Vite、Fastify、contracts、Drizzle、业务表及 PostgresSaver 初始化；匿名会话 cookie 和归属验证。创建开发、迁移、种子、检查、测试脚本与锁文件。

验收：页面可创建会话、发消息、刷新读取历史；两个浏览器上下文互相无法读取消息和 SSE；重复 clientMessageId 不产生两条消息；所有输入有 schema 校验；测试库独立于开发库。

## M2 须知问答和拍场工具

范围：OpenAI 适配器、RAGFlow 检索适配器、来源映射、虚构拍场种子、查询与规则推荐、基础 SSE。OpenAI Key 仅后端读取。

验收：须知回答含本次检索来源；无结果/过期资料不编造；实时拍场答案与数据库一致；模型不能任意执行 SQL；SSE 有增量和最终消息，刷新后最终答案完整。

## M3 多问题和受控工作流

范围：LangGraph 结构化规划、DAG 校验、串行调度、子任务输出依赖、预算、超时、取消和错误状态。

验收输入：“先告诉我演示参拍流程，再查下周北京的书画拍场，并帮我预约咨询”。按知识问答 → 拍场查询 → 预约选择/追问推进，不跳过缺失的拍场选择。循环依赖、未知工具、超预算、模型无效 JSON 均可控失败；只读超时不阻断已完成任务的展示。

## M4 表单与恢复

范围：结构化草稿、缺项追问、程序字段校验、确认版本、LangGraph interrupt/resume、运行租约、提交幂等。一个会话最多一个待处理表单。

验收：收集部分字段后重启 API，可继续；用户插问须知后返回原草稿；修改联系方式撤销旧确认；未确认不得提交；重复点击、HTTP 重试、恢复重放均只生成一条咨询回执。测试“数据库提交成功、检查点保存前崩溃”，恢复必须返回原回执。

## M5 重排 观测和故障评估

范围：先验证 Fastify 中的 OpenAI 应用层重排，比较启用前后质量；本地 Langfuse、脱敏 trace、固定评估问题集和故障注入。必须观察真实模型、检索和工具链路。原生 RAGFlow rerank provider 接入另作兼容性实验，未通过时不得把本项目写成已完成 RAGFlow 原生重排。

至少准备 40 条带预期结果的问题：须知 12、拍场 8、表单 8、多问题/插问 6、无结果/过期/异常 6。另加自动化隔离、重试和崩溃测试。检索集标注预期文档 ID/版本，业务集标注工具及参数，表单集标注最终字段及提交次数。

目标门槛：固定知识集 Recall@5 ≥ 90%；所有引用均来自实际有效片段；业务筛选结果与种子真值一致；提交重复数为 0；越权读取成功数为 0；恢复场景全部通过。延迟记录实际 p50/p95、模型和机器配置，不在未测前承诺响应秒数。质量门槛不足时分析切片、版本过滤、重排或规划错误，不靠改掉失败题隐藏问题。

## M6 完整容器演示与交接

范围：自有前后端 Dockerfile、多阶段构建、应用 Compose、前端反向代理 SSE、配置与数据备份说明。开发模式仍可保留宿主机热更新。

验收：用固定版本从空应用容器构建并连接已有依赖；浏览器完成“须知 → 查询 → 预约 → 确认 → 提交 → 重启查看历史”；PG/RAGFlow 数据经项目 data/ bind mounts 保留，其他服务按各自配置持久化；完整 trace 可查看；交接材料解释能力边界和故障处理。

## 必测故障矩阵

| 场景 | 预期行为 |
| --- | --- |
| RAGFlow 停止 | 明确检索不可用，不伪造知识回答；业务查询可独立执行 |
| OpenAI 无额度 | 标识余额/权限错误，停止自动重试，保存草稿 |
| Langfuse 停止 | 客服继续，记录观测故障，限制缓冲量 |
| API 在提交后崩溃 | 恢复同一回执，不再次提交 |
| 浏览器 SSE 断线 | 用事件序号补发，最终答案不重复 |
| 两次并发 resume | 取得执行权者推进，另一请求返回既有状态或冲突 |
| 旧版本表单确认 | 409，重新展示新摘要 |
| 用户 B 猜到用户 A 的 runId | 消息、事件、草稿和恢复均拒绝 |
| 知识文档含工具指令 | 只作为不可信资料，不执行越权工具 |
