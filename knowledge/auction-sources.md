# 拍卖目录演示数据与公开来源

核查日期：2026-11-27（Asia/Shanghai）。对应 TASK-006 r1。

用户允许参考中国嘉德官网公开的拍卖会和拍场。已访问 [官网](https://www.cguardian.com/) 和 [拍卖日程](https://www.cguardian.com/auctions/auction-preview)。日程页面返回 HTTP 200，但正文为客户端渲染空壳；浏览器读取也未取得可核实的具体场次。没有登录、绕过访问限制或进行大规模抓取。

没有从官网提取并确认任何正在进行的具体拍卖会/拍场名称、日期、状态或数量。搜索结果出现的第三方平台信息未作为“官网已核实”的数据使用。本轮不是实时爬虫或官网同步服务。

## 数据约定

- `apps/api/src/db/seeds/catalog.ts` 是人工编写的3场演示拍卖会、12个拍场，含6个类别和北京/上海两个演示城市。
- 拍卖会、拍场名称、地址、日程、厅名和数量均为虚构；每条记录 `isDemo=true`，并带 `sourceNote` 明确说明。
- `sourceUrl` 只是官方信息参考入口，不是本条记录真实存在的证据。页面必须同时显示演示声明，不能把链接标成“本场官方详情”。
- 日期固定为2026年8月、11月26–29日、12月5–6日，不随播种时间滚动。状态由服务端当前时间计算，起点包含、终点排除；以后演示数据变为全部已结束是预期行为，不应伪造仍在进行。
- 不包含真实客户、竞买人、成交金额、库存或预约名额，不从官网复制作品图像、长文或完整图录。

来源核查的机器可读记录为 `auction-source-check.json`。未来若取得可验证的官方数据，另存采集时间、原始日期文本、来源链接与确认状态；不得直接将本地虚构字段改标为官方事实。
